# AntiDupe 🛡️

Плагин для серверов Minecraft 1.18.2, предназначенный для обнаружения дюпов.

## Возможности
- ✅ Мониторинг подозрительных действий игроков
- ✅ Логирование попыток дюпа
- ✅ Настраиваемые правила через `config.yml`
- ✅ Автоматическое предупреждение администраторов

## Установка
1. Скачай последний релиз
2. Положи `.jar` в папку `plugins/` на сервере
3. Перезапусти сервер
4. Настрой `plugins/AntiDupe/config.yml` под свои нужды

## Команды
- `/antidupe reload` — перезагрузить конфигурацию
- `/antidupe player <player>` — проверить игрока на подозрительные действия

## Стек
- Java 17
- Spigot/Paper API 1.18.2
